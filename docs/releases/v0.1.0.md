# v0.1.0 - Initial Public Release

`cc-continue-task` is a Codex skill for saving and resuming long-running tasks across conversations.

## Highlights

- Save durable task handoffs under `.codex/handoffs/<task-id>/`.
- Preserve the task objective and original objective across saves.
- Distinguish user-specified and generated objectives.
- Detect and document objective drift.
- Include context loading plans and compression intent to reduce unnecessary project reloads.
- Automatically print a ready-to-paste resume prompt after saving a handoff.
- Provide helper scripts for creating, listing, validating, sanitizing, and resuming from handoffs.
- Include sanitized examples for common workflows.
- Include dependency-free tests and GitHub Actions CI.

## Helper Scripts

- `scripts/create_handoff.py`
- `scripts/list_handoffs.py`
- `scripts/make_resume_prompt.py`
- `scripts/validate_handoff.py`
- `scripts/sanitize_handoff.py`

## Safety

Generated handoffs may contain private paths, command output, issue details, or operational context. Run the sanitizer before sharing:

```powershell
python scripts/sanitize_handoff.py <handoff-path>
```

The sanitizer is a first-pass scanner. Review handoffs manually before publishing or attaching them.

## Install

Install under your Codex skills directory:

```text
<CODEX_HOME>/skills/cc-continue-task
```

See `docs/install.md` for details.
