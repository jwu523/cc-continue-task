# Examples

These examples are fictional and sanitized. They show the shape of useful handoffs without exposing real project paths, credentials, issue data, or command output.

- `basic/`: a normal checkpoint with a user-specified objective.
- `generated-objective/`: a checkpoint where the user did not specify an objective, so Codex generated one from the conversation.
- `objective-drift/`: a resumed task where the current work no longer matches the original objective, so the handoff recommends saving a new task instead of silently overwriting the original objective.
